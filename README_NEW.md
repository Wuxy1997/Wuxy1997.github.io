## 💻 本地开发

### 环境要求

- Node.js >= 12.0
- npm 或 yarn

### 安装依赖

```bash
npm install
```

### 本地预览

```bash
hexo server
```

访问 http://localhost:4000 查看博客

### 创建新文章

```bash
hexo new "文章标题"
```

### 生成静态文件

```bash
hexo generate
```

### 部署到 GitHub Pages

```bash
hexo deploy
```

## 📂 项目结构

```
Wuxy1997.github.io/
├── source/              # 源文件目录
│   ├── _posts/         # 博客文章
│   └── about/          # 关于页面
├── themes/             # 主题目录
│   └── particle/       # particle 主题
├── public/             # 生成的静态文件
├── _config.yml         # Hexo 配置文件
├── package.json        # 项目依赖
└── README.md          # 项目说明
```

## 🎨 主题配置

主题配置文件位于 `themes/particle/_config.yml`，可自定义：

- 头像和背景
- 导航菜单
- 侧边栏信息
- 社交链接
- 友情链接
- 主题样式（full / night / maiden）
